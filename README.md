# RClick — Real-Time Multiplayer Telegram Mini-Game

A high-performance, real-time multiplayer gaming backend built for the Telegram Mini Apps ecosystem.

## Key Features
* **Low-Latency Architecture:** Fast in-memory state management and caching using Redis to minimize response times during active gameplay.
* **Matchmaking & Logging:** Real-time room matchmaking system and persistent historical battle logs.
* **Global Reach:** Full localization support across 8 languages.

## Tech Stack
* **Language:** Python 3.11+
* **Backend Framework:** FastAPI
* **Database & Caching:** PostgreSQL, Redis
